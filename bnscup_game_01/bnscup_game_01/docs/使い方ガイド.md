# 季語シンクロ！ 使い方ガイド

## はじめに

「季語シンクロ！」へようこそ！このゲームでは、俳句の中から季語（きご）を見つけ出す力を楽しみながら身につけることができます。段位制システムで、初心者から上級者まで段階的に学習できます。

## ゲームの目的

俳句の中から季節を表す言葉（季語）を見つけ出し、クリックして選択してください。季語が含まれていない俳句の場合は「季語なし」ボタンを押してください。

## インストールと初期設定

### システム要件
- **OS**: Windows 10/11 (64bit)
- **CPU**: Intel Core i3相当以上
- **メモリ**: 4GB RAM以上
- **グラフィック**: DirectX 11対応GPU
- **ストレージ**: 500MB以上の空き容量

### 初回起動
1. ゲームを起動すると、設定ファイルが自動的に作成されます
2. 音量設定や画面サイズは設定ファイルで調整可能です
3. 初回プレイ時は「特待生」段位からスタートします

## 基本操作

### マウス操作
- **左クリック**: 季語を選択 / ボタンを押す
- **ホバー**: 文字の上にマウスを置くと強調表示されます

### キーボード操作
- **F3キー**: ヘルプ画面の表示/非表示
- **ESCキー**: ゲームを終了

## 段位システム

### 段位一覧
| 段位 | 名称   | 難易度 | 問題数 | 特徴                           |
| ---- | ------ | ------ | ------ | ------------------------------ |
| 0    | 特待生 | 初級   | 5問    | 基本的な季語、ふりがな完全表示 |
| 1    | 名人   | 中級   | 5問    | やや複雑な季語、ふりがな制限   |
| 2    | 達人   | 上級   | 5問    | 高度な季語、ふりがな最小限     |
| 3    | 俳人   | 最高位 | 全15問 | 全問題へのアクセス可能         |

### 昇段条件
- 各段位で5問を正解すると次の段位に昇段
- 俳人に到達すると全15問にアクセス可能
- 進捗は自動保存されます

## プレイ手順

### 1. ゲーム開始
1. タイトル画面で現在の段位を確認
2. 「ゲーム開始」ボタンをクリック
3. または段位選択ボタンで特定の段位を選択

### 2. 問題を解く
1. **俳句を読む**: 表示された俳句を注意深く読みます
2. **季語を探す**: 季節を表す言葉を探します
3. **選択する**: 
   - 季語がある場合：該当部分をクリック
   - 季語がない場合：「季語なし」ボタンをクリック

### 3. 結果確認
- **正解時**: 解説が表示され、次の問題に進みます
- **不正解時**: 再チャレンジできます
- 解説をよく読んで学習しましょう

### 4. 段位昇格
- 5問クリアすると自動的に次の段位に昇格
- 獲得したスコアは累計され、保存されます

## スコアシステム

### 基本得点
- **正解**: 100ポイント
- **速答ボーナス**: 最大50ポイント（解答時間に応じて）

### 段位別倍率
- **特待生**: 1.0倍
- **名人**: 1.2倍  
- **達人**: 1.5倍

### スコア計算例
特待生で10秒で正解した場合：
```
基本点: 100ポイント
速答ボーナス: 30ポイント
段位倍率: 1.0倍
合計: (100 + 30) × 1.0 = 130ポイント
```

## 季語について

### 季語とは
季語（きご）は、俳句に季節感を表現するために使われる言葉です。四季それぞれに対応する季語があります。

### 季節別季語の例

#### 春の季語
- **植物**: 桜（さくら）、梅（うめ）、菜の花（なのはな）
- **動物**: 蛙（かわず）、燕（つばめ）、蝶（ちょう）
- **気象**: 春風（はるかぜ）、霞（かすみ）、春雨（はるさめ）
- **行事**: 入学（にゅうがく）、花見（はなみ）

#### 夏の季語
- **植物**: 向日葵（ひまわり）、朝顔（あさがお）
- **動物**: 蝉（せみ）、蛍（ほたる）、金魚（きんぎょ）
- **気象**: 夕立（ゆうだち）、雷（かみなり）、夏雲（なつぐも）
- **行事**: 祭（まつり）、花火（はなび）、海水浴（かいすいよく）

#### 秋の季語
- **植物**: 紅葉（もみじ）、桔梗（ききょう）、萩（はぎ）
- **動物**: 虫（むし）、雁（かり）、鹿（しか）
- **気象**: 月（つき）、霧（きり）、木枯し（こがらし）
- **行事**: 月見（つきみ）、運動会（うんどうかい）

#### 冬の季語
- **植物**: 椿（つばき）、水仙（すいせん）、枯葉（かれは）
- **動物**: 白鳥（はくちょう）、狐（きつね）
- **気象**: 雪（ゆき）、氷（こおり）、霜（しも）
- **行事**: 正月（しょうがつ）、クリスマス

### 季語なしの俳句
すべての俳句に季語があるわけではありません。季語がない俳句もあり、その場合は「季語なし」が正解です。

## 設定とカスタマイズ

### 設定ファイル（config.json）の調整
ゲームの設定は `App/config.json` ファイルで調整できます：

```json
{
  "ui": {
    "clientSizeX": 1280,    // 画面幅
    "clientSizeY": 720,     // 画面高さ
    "wordWidth": 80         // 文字幅
  },
  "audio": {
    "bgmVolume": 0.4,       // BGM音量（0.0-1.0）
    "seVolume": 0.8         // 効果音音量（0.0-1.0）
  }
}
```

### 推奨設定
- **画面サイズ**: 1280×720（標準）、1920×1080（高解像度）
- **BGM音量**: 0.3-0.5（集中しやすい音量）
- **効果音音量**: 0.7-0.9（フィードバックがわかりやすい音量）

## トラブルシューティング

### よくある問題と解決方法

#### 1. ゲームが起動しない
**症状**: アプリケーションが起動しない、またはすぐに終了する

**解決方法**:
- PCを再起動してみてください
- Visual C++ Redistributableがインストールされているか確認
- DirectX 11対応グラフィックドライバーを更新
- ウイルス対策ソフトの除外設定を確認

#### 2. 音が出ない
**症状**: BGMや効果音が再生されない

**解決方法**:
- スピーカー/ヘッドフォンの接続を確認
- Windowsの音量ミキサーでアプリの音量を確認
- config.jsonの音量設定を確認
- 音響デバイスドライバーを更新

#### 3. 文字が表示されない・文字化けする
**症状**: 俳句や文字が正しく表示されない

**解決方法**:
- 日本語フォントが正しくインストールされているか確認
- config.jsonの文字コード設定を確認
- App/Yuji_Bokuフォルダの存在を確認

#### 4. セーブデータが保存されない
**症状**: 進捗やスコアが保存されない

**解決方法**:
- App/savedata.jsonファイルの読み書き権限を確認
- ディスクの空き容量を確認
- ウイルス対策ソフトの書き込み制限を確認

#### 5. 動作が重い・カクつく
**症状**: フレームレートが低い、動作が不安定

**解決方法**:
- グラフィックドライバーを最新版に更新
- 他のアプリケーションを終了してメモリを確保
- 画面解像度を下げる（config.jsonで調整）
- 電源プランを「高パフォーマンス」に設定

## データの管理

### セーブデータについて
- 進捗は自動的に保存されます
- セーブデータは `App/savedata.json` に保存されます
- 手動でバックアップを取ることをお勧めします

### セーブデータのバックアップ方法
1. `App/savedata.json` ファイルをコピー
2. 安全な場所に保存
3. 復元時は元の場所に戻す

### データのリセット方法
すべての進捗をリセットしたい場合：
1. ゲームを終了
2. `App/savedata.json` ファイルを削除
3. ゲームを再起動（新しいセーブデータが作成されます）

## よくある質問（FAQ）

### Q1: このゲームは何歳から遊べますか？
**A**: 小学校高学年（10歳）以上を想定していますが、ふりがな表示があるため、より若い年齢でも保護者と一緒に楽しめます。

### Q2: 俳句の知識がなくても大丈夫ですか？
**A**: はい、大丈夫です。特待生段位では基本的な季語から学習でき、詳しい解説も付いています。

### Q3: 段位は後で変更できますか？
**A**: はい。俳人段位に到達すると、すべての段位を自由に選択できるようになります。

### Q4: オフラインでも遊べますか？
**A**: はい。インターネット接続は不要で、完全にオフラインで遊べます。

### Q5: 複数のユーザーで使えますか？
**A**: 現在は単一ユーザー用ですが、セーブデータを手動でバックアップ・復元することで複数ユーザーに対応できます。

### Q6: モバイル版はありますか？
**A**: 現在はWindows版のみです。将来的な拡張は検討中です。
