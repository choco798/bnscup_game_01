# User Guide

## はじめに (Introduction)

「ブレバトの季語探しゲーム」へようこそ！このゲームでは、俳句の中から季語（きご）を見つけ出す力を楽しみながら身につけることができます。

Welcome to the Seasonal Word Finding Game! This game helps you learn to identify seasonal references (kigo) in Japanese haiku while having fun.

## ゲームの目的 (Game Objective)

俳句の中から季語を見つけ出し、クリックして選択してください。季語が含まれていない俳句の場合は「季語なし」ボタンを押してください。

Find and click on the seasonal reference (kigo) within the haiku. If there is no seasonal reference, click the "No Kigo" button.

## 操作方法 (Controls)

- **マウス操作 (Mouse Controls)**
  - 左クリック：季語を選択 / ボタンを押す
  - ホバー：文字の上にマウスを置くと強調表示

- **キーボード操作 (Keyboard Controls)**
  - F3：ヘルプ画面の表示/非表示
  - ESC：ゲームを終了

## 段位システム (Grade System)

### 1. 特待生 (Trainee)
- 初級レベル
- 基本的な季語を学ぶ
- フリガナのサポートあり
- 5問クリアで昇級

### 2. 名人 (Master)
- 中級レベル
- より複雑な季語
- 限定的なフリガナ
- 5問クリアで昇級

### 3. 達人 (Expert)
- 上級レベル
- 高度な季語の理解
- 最小限のフリガナ
- 5問クリアで最終段位へ

### 4. 俳人 (Haijin)
- 最終段位
- すべての問題にアクセス可能
- 完全な季語マスター

## プレイ手順 (How to Play)

1. **開始方法 (Starting the Game)**
   - タイトル画面で現在の段位を確認
   - 「開始」ボタンをクリック
   - 段位に応じた問題が出題される

2. **季語の判断 (Identifying Kigo)**
   - 俳句を注意深く読む
   - 季節を表す言葉を探す
   - 該当部分をクリック、または「季語なし」を選択

3. **結果確認 (Checking Results)**
   - 正解：説明と共に次の問題へ
   - 不正解：再チャレンジ可能

4. **段位の上昇 (Grade Progression)**
   - 各段位で5問をクリア
   - 自動的に次の段位へ昇級
   - 獲得したスコアは保存される

## スコアシステム (Scoring System)

- **基本点 (Base Points)**
  - 正解：100点
  - 素早い回答でボーナス点

- **段位ボーナス (Grade Bonus)**
  - 特待生：x1.0
  - 名人：x1.2
  - 達人：x1.5

## ヘルプ機能 (Help Feature)

- F3キーでいつでも表示可能
- 基本的な操作方法を確認
- 季語についての説明
- 閉じるボタンで元の画面に戻る

## 音声設定 (Sound Settings)

設定で調整可能な項目：
- マスター音量
- BGM音量
- 効果音音量

## トラブルシューティング (Troubleshooting)

### よくある問題 (Common Issues)

1. **ゲームが起動しない (Game Won't Start)**
   - PCの再起動を試してください
   - インストールの再実行

2. **音が出ない (No Sound)**
   - 音量設定の確認
   - スピーカー接続の確認

3. **画面が表示されない (Display Issues)**
   - 画面解像度の確認
   - グラフィックドライバーの更新

## ゲームの終了方法 (Exiting the Game)

1. ESCキーを押す
2. 確認ダイアログで「はい」を選択

## データの保存 (Save Data)

- 進行状況は自動保存
- 段位の記録は維持
- スコアは累積で記録

## プレイのコツ (Playing Tips)

1. **季語の特徴 (Kigo Characteristics)**
   - 自然現象への言及
   - 季節の風物詩
   - 伝統的な行事

2. **効率的な学習 (Efficient Learning)**
   - 解説をよく読む
   - 間違えた問題を記録
   - 段階的に難しい問題に挑戦

3. **スコアを上げるコツ (Score Improvement)**
   - 素早い判断を心がける
   - 説明をよく理解する
   - 定期的な練習

## 付録 (Appendix)

### 季語の例 (Example Kigo)

春の季語 (Spring)
- 桜 (さくら) - Cherry blossoms
- 蛙 (かわず) - Frog
- 春風 (はるかぜ) - Spring breeze

夏の季語 (Summer)
- 波 (なみ) - Waves
- 蝉 (せみ) - Cicada
- 夕立 (ゆうだち) - Summer shower

秋の季語 (Autumn)
- 月 (つき) - Moon
- 紅葉 (もみじ) - Autumn leaves
- 虫の声 (むしのこえ) - Insect sounds

冬の季語 (Winter)
- 雪 (ゆき) - Snow
- 北風 (きたかぜ) - North wind
- 炬燵 (こたつ) - Kotatsu
