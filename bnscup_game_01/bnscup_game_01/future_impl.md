# 大きな方針

## ゲーム性の強化
### 俳句の問題リストの拡充、目指せ百人一首！15問まで
* 段位に応じた俳句が出題されるように修正。もっと繰り返し遊びたくなるように、各5問
  * タイトル(TitleScene.cpp)で何も選択せずに開始したら今の段位、段位が特待生、名人、達人、俳人（最大、全部遊べる）に上がるにつれて、1個前のモードを遊べるボタンが追加されていくようにする
  * problems.jsonのgrade0,1,2が特待生、名人、達人と対応している、`bool ProblemManager::loadFromJSON(const FilePath& path)`に読み込み機能追加
* 段位の上昇の仕方の調整
  * 各5問、クリアすると、段階上がる、特待生＝＞名人＝＞達人＝＞俳人（15問）、`GameState::ranks`などを調整
* 段位と、合計スコアをファイル（savedata.ini）に保存しておくようにする
  * タイトル(TitleScene.cpp)に合計スコアも表示する
* 解説に、季語と作者は別で表示する部分を追加する、`void Renderer::drawExplanation(const String& text) const`へ機能追加
  * problems.jsonのkigoとauthorを表示する
* フリガナを表示できるようにする(GameScene.cppとRenderer.cpp)
  * 1行の間隔をあけて、ruby内の漢字と1文字ずつ比較して合致していたら()内のテキストをその内容を表示する
* 短歌を表示できるようにする、改行ごとに字下げしている部分を調整する必要がある(Renderer.cpp))

## 音楽性の強化
* 俳句の位置を左側にずらして、右側にリズム譜を追加する
  * problems.jsonのrhythm部分を読み取って、ボタンを押すとリズム符記号を出しながら、一緒に準備したサウンドを再生するようにする
* マイクを使って、季語のところで発音されていたらエフェクトを出したい！
  * マイク入力を受け取る方法と、発音されている場所とされていない場所の判定を追加する
* パーカッションとしては、和太鼓がよさそう。サウンドリソース側で対応する


App/problems.jsonに実際のデータが準備済み
```json
{
  "gameTitle": "ブレバトの季語探しゲーム",
  "version": "1.0",
  "problems": [
    {
      "id": "furuike_001",           // 問題の一意なID
      "author": "松尾芭蕉",           // 作者名
      "source": "俳諧",               // 出典（俳諧・百人一首など）
      "text": "古池や 蛙飛びこむ 水の音",      // 俳句本文（原文）
      "ruby": "古(ふる)池(いけ)や 蛙(かわず)飛(と)びこむ 水(みず)の音(おと)", // ルビ付き表示用
      "rhythm": "44444!64444444!644444",         // リズム情報（音の長さ・区切り）
      "hasKigo": true,              // 季語の有無（true/false）
      "kigo": "蛙",                 // 季語（文字列）
      "kigoStart": 4,               // 季語の開始位置（文字インデックス）
      "kigoEnd": 5,                 // 季語の終了位置（文字インデックス）
      "explanation": "芭蕉が自然の静けさと生命の音を*感じ取った代表作です。", // 説明（中学生1年生向けに調整してあります）
      "note": "",                   // 補足情報（例：季語なしボタンが正解 等）
      "tags": ["春","有名句"],       // タグ（季節・特徴など）
      "grade": 0,                   // 難易度（0=やさしい、1=ふつう、2=むずかしい）
      "displayRuby": true           // ルビ表示の有無
    }
  ]
}
```
